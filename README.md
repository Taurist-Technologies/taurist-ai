# Taurist AI

Landing page for Taurist Technologies' AI services offering — hosted via GitHub Pages.

## Structure

- `index.html` — landing page (served as the site root)
- `assets/` — images, logos, and supporting media

## Local preview

```bash
# From the repo root
python3 -m http.server 8000
# then open http://localhost:8000
```

## Deployment

This repo is served by GitHub Pages from the `main` branch root. Any push to `main` triggers a rebuild — usually live within a minute.

Live URL: https://taurist-technologies.github.io/taurist-ai/
